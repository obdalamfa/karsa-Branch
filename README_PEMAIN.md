# Lembah Karsa 3D

Game bertani & sim-life folklor Nusantara — rasa *Disco Elysium* × *Project Zomboid*,
NPC ala *The Sims*, pertanian mendalam ala *Sakuna*.

## Cara Main (versi bundel)
1. Ekstrak seluruh folder `LembahKarsa3D`.
2. Jalankan **`LembahKarsa3D.exe`**.
3. Layar judul → **Mulai Baru** → buat karaktermu → ikuti surat Paman Arsa.

> Simpan seluruh folder apa adanya — `LembahKarsa3D.exe` butuh folder `_internal`
> di sebelahnya. File simpanan (`lembah_karsa_3d_save*.json`) tertulis di folder ini.

## Kontrol
| Tombol | Aksi |
|---|---|
| **WASD** | Jalan |
| **Q / E** | Putar kamera |
| **Spasi / E** | Interaksi (cangkul, tanam, panen, bicara) |
| **R** | Rawat petak / perah ternak |
| **I** | Inventaris |
| **J** | Jurnal misi |
| **TAB** | Majelis Batin (4 suara batin + skill-check) |
| **Esc** | Menu Jeda (Simpan / Muat / Pengaturan / Kontrol) |

## Loop Harian
Cangkul → tanam → **siram tiap hari** (jadwal air ala Sakuna menentukan mutu ★) →
panen → masukkan ke **Peti Kirim** → **tidur** → emas masuk saat fajar.
Rawat ternak [R] untuk susu/telur/wol. Jelajah gua untuk bijih & lawan mob
(perhatikan **telegraph merah** sebelum mereka memukul — mengelaklah!).

## Tip
- Volume & layar penuh diatur di **Esc → Pengaturan**.
- 3 slot simpanan tersedia di **Esc → Simpan / Muat**.

Selamat bertani di Lembah Karsa. 🌾
